Valid date values:
[YYYY]
[MM-DD]
[YYYY-MM-DD] 

Valid time values:
[HH:MM]
[HH:MM:SS]

Any combination of date and time can exist.
- If no date is specified at all, then assume the date is TODAY.
- If a year is not specified, assume the current year
- If the month and day are not specified, assume 01-01
- If seconds are not specified, assume 00
- If no time values are specified, assume 00:00:00
